Olá, nesta pasta: NPS - Ecommerce BR - EDA do repositório: I Scientist você encontra:
- O notebook Jupyter utilizado para exploração dos dados de NPS (.ipynb)
- A base csv bruta utilizada como fonte do notebook (.csv)
- O ppt utilizado como apresentação executiva (.pptx)

Este case aborda uma análise exploratória de dados que foi feita para um ecommerce brasileiro que enfrentava desafios de captar o perfil de consumo dos seus clientes depois de uma grande expansão. A exploração é feita a partir de uma pesquisa NPS realizada como ponto de partida para implementação de estratégias de aumento de receita e redução de churn.
